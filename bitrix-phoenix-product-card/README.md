# Карточка товара ITALICA — кастомные стили для 1С-Битрикс «ФЕНИКС»

Готовый комплект для карточки товара: только CSS и JS.
**PHP, шаблоны компонентов и HTML не трогаем** — всё сделано на родных классах и id
решения ФЕНИКС (`concept.phoenix`), поэтому переживает обновления шаблона.

```
bitrix-phoenix-product-card/
├── product-card.css   ← вставить в поле «Свой CSS»
├── product-card.js    ← вставить в поле «Свой JS»
├── README.md
└── preview/           ← статическая копия разметки ФЕНИКС для предпросмотра
    ├── index.html     (открыть/запустить локально — видно итоговый дизайн)
    ├── grid.css       (мини-аналог bootstrap-сетки, нужен ТОЛЬКО для предпросмотра)
    └── preview.js     (имитация поведения ядра, нужен ТОЛЬКО для предпросмотра)
```

---

## 1. Установка

1. Админка Битрикс → **Пульт управления ФЕНИКС** (Конструктор) → **Настройки** →
   раздел со своим кодом → поля **«Свой CSS»** и **«Свой JS»**
   (в разных версиях: *Настройки → Шаблон → Свой CSS / Свой JS*).
2. Содержимое `product-card.css` — в поле CSS, `product-card.js` — в поле JS.
3. **Очистить кэш**: Настройки → Кэширование → «Очистить кэш» (и кэш компонентов /
   композит), иначе старые стили могут отдаваться из кэша.
4. Открыть карточку товара и обновить страницу с `Ctrl+F5`.

> Поля «Свой CSS / Свой JS» в ФЕНИКСе специально сделаны так, чтобы не затираться
> обновлениями решения. Если такого поля нет — вставьте код в
> *Конструктор → страницы/шаблон → блок «HTML-код»* или подключите файлы через
> `header.php` (последнее потребует доступа к файлам).

## 2. Что именно меняется

| Зона | Что сделано |
|---|---|
| **Заголовки всех блоков** (`#chars`, `#similar`, `#accessory`, `#news_list`, `#text`) | Единая типографика, номер секции `01 / 02 / 03`, тонкая линия, уходящая в никуда |
| **Галерея** (`.info-left-side`) | Белая рамка-карточка с hairline, превью — квадраты 1:1 с активным контуром, счётчик «03 / 08», метки («Хит», «Акция») — аккуратные чипы |
| **Панель покупки** (`.info-right-side-inner`) | Плотная карточка с рамкой и мягкой тенью, «липкая» на десктопе (ставится JS, только если панель влезает в экран) |
| **Артикул / наличие** | Артикул — мелкий трекинг- Uppercase, наличие — точка-индикатор с тоном: зелёный / янтарный («мало») / красный («нет») |
| **Цена** (`#actual_price`) | Крупная цифра табличным шрифтом (не «дрожит» при пересчёте), перечёркнутая старая цена, скидка — чип в фирменном цвете |
| **Количество и сумма** | Аккуратный stepper 46 px, скрыты системные стрелки `input[type=number]`, сумма — справа, табличными цифрами |
| **Кнопки** | «В корзину» остаётся в фирменном цвете шаблона (геометрия, типографика, отклик — новые), «Заказ в 1 клик» — контурная, «Уже в корзине» — контур зелёного |
| **Характеристики** (`#chars`) | Читабельные строки «подпись — точка — значение», hover-подсветка строки, «Показать все» со стрелкой |
| **Файлы** (инструкции) | Плашка-документ: иконка нарисована на CSS, hover-подъём |
| **Похожие / сопутствующие** | Карточки в рамке, hover-подъём, название в 3 строки, цена табличными цифрами |
| **Текстовые блоки** | Читабельная ширина строки (`72ch`), свои заголовки и списки |

Никаких новых блоков, секций и контента: работаем только с тем, что уже выводит ФЕНИКС.

## 3. Идея дизайна

Концепция **«Цех»** — технический каталог, а не «воздушный ИИ-лендинг»:

* мелкая типографика с трекингом рядом с крупной ценой — контраст масштаба;
* hairline-линейки (1 px) вместо теней и градиентов;
* нумерация секций `01 / 02` — как в каталоге деталей;
* табличные цифры (`font-variant-numeric: tabular-nums`) — цена не пляшет;
* почти прямые углы (радиус 3 px) — «металлический» характер;
* акцент **не свой**: JS считывает фон кнопки «В корзину» (фирменный цвет шаблона)
  и подставляет его в акценты карточки — карточка не спорит с остальным сайтом.

## 4. Настройка под себя

Все переменные — в начале `product-card.css`:

```css
--ital-accent:      #b06a2c;  /* акцент (JS подменяет на фирменный цвет) */
--ital-ink:         #14181d;  /* основной текст */
--ital-line:        #e3e6ea;  /* цвет hairline-линеек */
--ital-r:           3px;      /* радиус углов */
--ital-font:        "Inter", ...;  /* шрифт карточки */
```

Если фирменный цвет подхватывать не нужно — удалите функцию `pickAccent()`
из `product-card.js`, тогда останется `--ital-accent` из CSS.

Подключить свой шрифт (по желанию): добавьте `@font-face` в начало CSS и впишите
семейство первым в `--ital-font`. По умолчанию используется системный стек —
ничего не грузится со стороны, скорость не страдает.

## 5. Технические детали

* **Ничего не скрывается насовсем.** Плавное появление блоков включается только
  если JS отработал (класс `ital-js` на `<html>`): без JS или при ошибке всё
  отображается сразу.
* **Аккуратно с аяксом ФЕНИКС.** При выборе торгового предложения шаблон
  перерисовывает цену, количество и галерею — `MutationObserver` в JS
  пересчитывает счётчик, наличие и «липкость» панели.
* **Адаптив.** На ≤767 px превью галереи переносятся под главное фото,
  панель покупки теряет рамку и тень, кнопки становятся в один столбец.
* **`prefers-reduced-motion`** — анимации и появление отключаются.
* **GSAP не обязателен.** Если на странице уже есть GSAP, JS использует его для
  появления блоков; если нет — работает на CSS-переходах. Внешних зависимостей нет.

## 6. Если что-то не применилось

Версии ФЕНИКС (s2/s3/…) местами меняют классы. Быстрая проверка:

1. Откройте карточку, нажмите `F12`, выберите элемент-цену и посмотрите его классы.
2. Если классы отличаются от тех, что в селекторах файла — пришлите скопированный
   HTML блока (`F12` → ПКМ по `#main` → *Copy → Copy outerHTML*), я перепривяжу селекторы.

Основные точки привязки: `#main`, `.catalog-item`, `.info-left-side`,
`.info-right-side-inner`, `#actual_price`, `.quantity-container`,
`.wrapper-btns`, `#chars .cart-char-table`, `.cart-title`, `.item-inner`.

## 7. Предпросмотр

`preview/index.html` — статическая копия разметки ФЕНИКС с реальными фото и
текстами вашей карточки. Можно открыть файлом или поднять локальный сервер:

```bash
cd bitrix-phoenix-product-card/preview
python3 -m http.server 8080
# http://localhost:8080
```

Файлы `preview/grid.css` и `preview/preview.js` нужны только для этой копии —
на сайт их загружать не нужно.
